# An in-memory cache for Denote

An optional, in-memory cache that can speed up all sorts of Denote
operations, such as for retrieving backlinks and finding the path to a
given Denote identifier. This package can open up new possibilities,
as its data can be used to display a graph or other visuals, use it
for `completion-at-point-functions`, and more.

+ Package name (GNU ELPA): `denote-data` (⚠️ Coming soon!)
+ Git repository: <https://github.com/protesilaos/denote-data>
+ Backronym: DENOTE ... Data Assiduously Transferred Asynchronously.
